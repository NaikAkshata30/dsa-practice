## About

This is my growing collection of Python solutions from the [TLE Eliminators CP-31 Sheet](https://www.tle-eliminators.com/cp-sheet). I use it to practise consistently, recognise reusable patterns, and build confidence before moving to harder ratings.

Each solution keeps the original problem-solving record intact and includes a short explanation of the key idea for revision.
